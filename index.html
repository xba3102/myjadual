Import Data aSc Timetables

Panduan Eksport dari aSc Timetables:

  1. Buka perisian aSc Timetables.
  2. Pergi ke menu File > Export > MS Excel atau Export to HTML.
  3. (Disyorkan) Pilih eksport format List of Lessons kerana ia lebih mudah diproses.
  4. Muat naik fail .xlsx, .xls, atau .html tersebut di bawah.
